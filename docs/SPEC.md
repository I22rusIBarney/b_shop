# BobrGO Shop — карта функций (по скриншотам текущего бота)

Источник: скриншоты клиентского веб-аппа от 2026-10-13. Код RWP не используется, только описание поведения.
Оплата: только ЮKassa. Веб-апп: Telegram Mini App + обычный браузер (PWA). Вход: Telegram, email-код, Яндекс ID, VK ID.

## Навигация (нижняя панель)
- Главная · Поддержка · Профиль · Админка (иконка щита, только для админов)

## Главная
- Переключатель подписок («Подписка 1 ▾»), карусель подписок, «+» — добавить ещё подписку (мультиподписка)
- Карточка подписки: тариф (эмодзи + название), дата окончания, «N/M устройств» с переходом к управлению устройствами
- Ссылка подписки (замаскирована) + копирование
- Кнопки: Продлить · Установить и настроить · Сменить тариф
- Брендинг: фон-картинка, логотип, слоган

## Продление / покупка
- Сетка периодов 1/3/6/12 мес: старая цена зачёркнута, новая цена, цена за месяц, бейдж «Лучший выбор»
- Персональная скидка клиента применяется к ценам
- Блок «Ваш выбор» (тариф × период, сумма), «Что входит в подписку» (список пунктов тарифа)
- Итого (со старой ценой) + «Оплатить»

## Смена тарифа
- Текущий тариф: трафик, устройства, цена/мес, остаток дней
- Режимы: Доплата (платишь разницу, дни сохраняются) · Конвертация (без оплаты, дни пересчитываются) · Понижение (дни конвертируются в больший срок)
- Бейдж персональной скидки
- Список тарифов: трафик, устройства, цена/мес, тип перехода, пересчёт «X → Y дней», подсказка (?) с описанием

## Установка
- Автоопределение платформы (iOS/Android/Windows/macOS/TV), «Другое устройство?»
- Блок «Поделиться ссылкой»: QR, Поделиться, Скопировать
- Шаги: 1) установить клиент (INCY, ссылка в стор) 2) «Добавить подписку» — deeplink в клиент 3) подключиться

## ПРИНЦИП: всё настраивается из админки
- Никаких захардкоженных значений: реферальные бонусы/уровни/%, тарифы, тексты, кнопки, ссылки, каналы, таймеры, лимиты, ИИ, шаблоны писем, автоматизации — всё хранится в БД и редактируется в веб-админке

- Рефералка: уровни — динамический список (добавить/удалить уровень: «от N приглашённых → X дней»), а не фиксированные 3 поля

### Статистика → Обзор (одна длинная страница)
- Пользователи: сегменты Истекает ≤7д / Активные / Без срока / Истекла ≤30д / Истекла давно / Без подписки; колонки Все / Заблокировали бота / Заблокированы / Подозрительные; итого; DAU/MAU, новые сегодня/неделя

- Доходы: сегодня / неделя / месяц (с % к прошлому периоду), средний чек, за всё время
- Графики с периодом 7д/1м/3м/6м/12м и группировкой дни/недели/месяцы: новые пользователи, доходы
- География подключений (глобус/карта, список город: кол-во) — по IP из Remnawave
- По способам оплаты (кол-во платежей, сумма)
- Реферальная программа: всего рефералов, активных рефереров, бонусных дней, конверсия
- Промокоды: всего, активных, использований, бонусных дней
- По тарифам (покупки: кол-во и сумма), по периодам 1/3/6/12 мес
- Покупки (стек-бары по неделям): по тарифам, по периодам, по типам операций (покупка / повышение)
- Автоплатежи: с автоплатежом, с сохранённым методом
- Триал: использовали / оплатили / конверсия
- Трафик (докупка): покупок, ГБ, сумма
- Входы: сессии, уникальные сегодня/неделя/месяц, по методам (Telegram/Email/Google/Яндекс/VK)
- PWA-установки; по языкам

### Статистика → Юнит-экономика (период 3/6/12м)
- Карточки: MRR (+% MoM), ARR, активные подписчики, отток %, ARPPU, срок жизни, LTV, NRR, Quick Ratio
- Графики: динамика MRR; компоненты MRR (новый/реактивация/расширение/отток); мостик MRR за месяц; чистый рост MRR
- Детализация по месяцам: MRR, новый, реактивация, расширение, отток, активные, ушли, ARPPU, Net
- Подписчики активные vs ушедшие (бары); ARPPU по месяцам
- Удержание: дней до оттока, % реактивации, churn по месяцам (под риском / ушли / остались / %)
- Когортный анализ M0–M5 (% удержания) и доход по когортам на юзера

- Детализация LTV: платящих (конверсия), дней до 1-й оплаты (среднее/медиана), всего юзеров; LTV по источникам (прямой/реферальный); LTV по тарифам (+ доля)

### Статистика → Платежи (период 1н–12м, дни/недели/месяцы)
- Попыток, успешных (конверсия в оплату), неудачных, Retry Success %, Autopay %
- Графики: конверсия платежей (успех/неудача по дням), платежи по системам

### Статистика → Рефералы (период 7д…всё время)
- Всего рефералов, оплативших, выданных дней, выручка от рефери, стоимость бонусов, ROI
- Графики: новые рефералы и оплаты; бонусные дни по типам (первый/повторный/приглашённому); выручка vs стоимость; cumulative ROI
- Типы бонусов; воронка приглашённых (приглашены → начали оформление → оплатили → повторно)
- LTV приглашённый vs обычный; топ рефереров; лента последних бонусов (когда, тип, дней, реферер, приглашённый)
- Механика бонусов: рефереру за первую и каждую повторную оплату реферала (3 дня), приглашённому — бонус (3 дня); тиры есть, но не используются

### Статистика → Поддержка

### Abuse Detection (шеринг подписок)
- Скан нод каждые 15/30/60 мин, ручной запуск, «Проверить HWID»
- Порог: уникальных IP > лимит устройств × множитель (×2/×3/×4); порог трафика на устройство; N чистых проверок для снятия флага; история 90 дн.
- Реакция: сбросить соединения / отключить юзера; уведомление админам в TG
- Мультиаккаунты (только Free/Trial): общий HWID или IP
- Глобус/карта тепловая по IP, таймлайн проверок, список с кол-вом уникальных IP, фильтр «только нарушители»
- Текущее: включено, ×3, сброс соединений вкл, нарушителей 0 → оставить упрощённо (список «много IP» + ручная реакция), глобус не нужен
